How to install

  1. 1Tap Download for Android and wait for the file to finish.
  2. 2Open the downloaded file. If Android asks, allow your browser to install unknown apps, then tap Install.
  3. 3Open Hikari Street from your apps. That's it: the app always opens the latest version of the game, so you never need to update it.

Why the app?

  • Always up to date: every improvement reaches you the next time you open it.
  • Full screen, like any game, with the screen kept on while you play.
  • Your phone treats it as a game: Game Booster and Android's game modes apply.
  • Reads your phone's temperature and eases the graphics before it gets hot, so it stays smooth for longer.
