# Instructions for AI coding assistants

Read [`CLAUDE.md`](CLAUDE.md) before making any change, and
[`PORTING.md`](PORTING.md) when porting from the original game. They hold this
project's code-quality rules, performance rules and the checks to run before
committing. They apply to every assistant and tool, not only Claude.

In short: write only clean, optimized, leak-free code that keeps the game
smooth on phones and identical to the original. Measure instead of guessing,
and never leave the game broken.
